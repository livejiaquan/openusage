# Remote Devices

Settings → Remote Devices lets you add a machine whose Claude Code or Codex CLI history lives outside this Mac. Enter its SSH host alias, DNS name, or IPv4 address. If you use an IP address, enter the SSH username explicitly when it differs from your Mac username; an alias can also supply the username, port, and key through `~/.ssh/config`. **Advanced SSH** contains the optional port override. **Check SSH** checks authentication and Python and shows the remote user and home folder; it does not check usage logs. Changing the connection details clears that result. Saving imports the history. Invalid fields show their own explanation and the first invalid field receives keyboard focus. An existing device can be edited without changing its identity.

Choose **Windows + WSL** under **Read Logs From** when SSH connects to a Windows host and logs are in WSL. **Windows Username** is the account used for SSH. **WSL Environment** contains the optional distribution and **Linux Username**, which select the Linux home folder containing the logs. **Windows** reads the Windows account's own logs. **Linux** and **Mac** run Python directly under the SSH account. Direct SSH into a WSL distribution uses **Linux**. The remote user needs Python 3 and read access to their CLI logs. Connect once in Terminal first so the SSH host key is known; OpenUsage uses existing SSH keys and never stores a password.

OpenUsage sends its bundled Python exporter over SSH stdin on each refresh. The script reads `~/.codex/sessions`, `~/.codex/archived_sessions`, and `~/.claude/projects` (or their supported environment-variable roots). It returns only timestamps, model names, token buckets, and deduplication IDs. Prompts, replies, credentials, and raw JSONL lines are not sent. The remote machine stores a private, incremental parsed-event cache in `~/.cache/openusage-remote/events-v1.json`; this Mac stores only the priced daily summary and the device settings. Removing a device deletes its summary and settings on this Mac, but leaves the remote cache in place.

OpenUsage refreshes connected devices during its normal refresh loop and keeps the last good summary if a device is offline. Each device row shows whether it is importing, imported, empty, paused, or not imported yet. **Refresh** is directly available on the row. A failed import shows **Retry** and expandable error details, alongside the last successful import time when saved history exists. A newly saved device remains listed even if its first import fails. Open its actions menu to Edit or Remove it. **Add Device** opens a separate draft; Cancel leaves saved settings unchanged. Optional WSL and SSH fields expand only when needed. On the dashboard, **Usage From** can show All Devices, This Mac, or one connected device. This changes the historical usage rows and Total Spend, while live account quota meters remain this Mac's own values.

The combined history is additive for local-log providers. Cursor's account-wide history is never added across devices. Avoid pointing two configured sources at copies of the same session files; for example, remove the old extra-log-root folder after migrating that device to SSH. Likewise, do not add a Mac already included through iCloud as a separate SSH source. These sources have distinct device IDs and cannot prove that copied session files are the same physical usage.

The exporter is versioned with the app. A device with a different or missing Python runtime reports an error rather than silently producing a zero. On Windows, install Python 3 if `py -3` is unavailable. On WSL, the Windows SSH login must be able to run `wsl.exe --exec python3 -` for the intended Linux user; select a distribution or user in Settings when the default is wrong. Changing a device's connection clears its old summary before importing from the new account.

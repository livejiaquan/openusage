# Remote Devices

Settings → Remote Devices lets you add a machine whose Claude Code or Codex CLI history lives outside this Mac. Give it a display name, an SSH host alias or DNS name, and the system to run the scan on. **Windows WSL** connects to the Windows SSH server and invokes `wsl.exe`; **Windows** scans Windows user files; **Linux** and **Mac** run Python directly. The remote user needs Python 3 and read access to their own CLI logs. Connect once in Terminal first so the SSH host key is known; OpenUsage uses existing SSH keys and never stores a password.

OpenUsage sends its bundled Python exporter over SSH stdin on each refresh. The script reads `~/.codex/sessions`, `~/.codex/archived_sessions`, and `~/.claude/projects` (or their supported environment-variable roots). It returns only timestamps, model names, token buckets, and deduplication IDs. Prompts, replies, credentials, and raw JSONL lines are not sent. The remote machine stores a private, incremental parsed-event cache in `~/.cache/openusage-remote/events-v1.json`; this Mac stores only the priced daily summary and the device settings. Removing a device deletes its summary and settings on this Mac, but leaves the remote cache in place.

OpenUsage refreshes connected devices during its normal refresh loop and keeps the last good summary if a device is offline. Settings shows the last successful update or an SSH error; each device has Refresh and Remove actions. On the dashboard, **Usage From** can show All Devices, This Mac, or one connected device. This changes the historical usage rows and Total Spend, while live account quota meters remain this Mac's own values.

The combined history is additive for local-log providers. Cursor's account-wide history is never added across devices. Avoid pointing two configured sources at copies of the same session files; for example, remove the old extra-log-root folder after migrating that device to SSH. Likewise, do not add a Mac already included through iCloud as a separate SSH source. These sources have distinct device IDs and cannot prove that copied session files are the same physical usage.

The exporter is versioned with the app. A device with a different or missing Python runtime reports an error rather than silently producing a zero. On Windows, install Python 3 if `py -3` is unavailable. On WSL, the Windows SSH login must be able to run `wsl.exe -e python3 -` for the intended Linux user.
